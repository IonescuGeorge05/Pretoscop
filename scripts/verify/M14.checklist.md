M14 — 5-minute founder check (search, categories, brands, shops)
1. Start the worker (it rebuilds the search index at start when Meilisearch has none, then syncs every
   minute) and the web app: `make dev`, or `pnpm --filter @pretoscop/worker search:rebuild` once and
   `pnpm --filter @pretoscop/web dev`.
2. Search "tigaie" (no result: says what Pretoscop covers and links the categories), "televizor",
   "iphone 17 pro 256" (the 256 GB Pro first, never the 512 GB one) and "frigider side by side"
   (today: no fridges yet, so it says so). Try "televzor" (typo) and "consolă" (diacritics).
3. In the header box type "iph": suggestions for products (with prices), categories and brands
   appear; arrow keys + Enter open one; Escape closes. With JavaScript off the box still searches.
4. Open a category (/categorii → Televizoare): products by popularity then price, brand chips
   (→ "Televizoare Samsung"), pagination; empty categories say "în curând" instead of a blank page.
5. Open /magazin/emag and /magazin/altex: coverage and freshness facts, how we collect prices,
   delivery honesty ("nu am verificat încă tarifele") and, for Altex, why it is not included.
6. Change a product title in /admin/produse; within 2 minutes (worker running) search finds the new
   title. Or: `pnpm --filter @pretoscop/worker search query "<new words>"`.
7. `make verify M=14` prints OK.
