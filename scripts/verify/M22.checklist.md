# M22 founder checklist (5 minutes)

No Anthropic key exists yet (setup A9), so nothing here calls Claude: the LLM is off (no key, flag
`llm.matching.enabled` off) and the checks below show the pipeline, the cap and the admin. The real
precision is measured by one command once the key exists (step 6).

1. **Admin spend.** Log in at `/admin`. The card "LLM (luna)" shows month-to-date spend against the cap
   (`0,00 € / 50 €`, "0 % din plafon"). It turns "atenție: peste 80 %" at 80 % and "OPRIT: plafon
   atins" at 100 %, when no request is sent any more.
2. **What would be sent.** `pnpm --filter @pretoscop/worker llm:match --dry-run --limit 20`: the review
   items the LLM would check (Haiku 5.5; Sonnet 5.5 for items of 3.000 lei or more), the worst case
   reserved under the cap and the estimated cost. Nothing is sent.
3. **Review queue before/after a batch run (mock).** `pnpm --filter @pretoscop/worker llm:match --mock --limit 30`
   runs the whole flow against a local stand-in (our own rules, not Claude) and prints each decision
   and "queue would go N → M". It writes nothing (the queue on `/admin/potriviri` is unchanged).
4. **Sample LLM decisions and undo.** `make verify M=22` runs a Playwright check that creates one LLM
   accept, shows it under "Decizii LLM" on `/admin/potriviri` with "Corect" and "Înapoi la
   verificare", sends it back to the queue (audited `llm.revert`) and removes it afterwards. Once the
   LLM runs for real, open that section and check 10 LLM-accepted matches with the links.
5. **Spend from the ledger.** `pnpm --filter @pretoscop/worker llm:spend`: cap, billed, in flight, by
   model, cache share, cost per 1,000 pair verifications.
6. **After A9 (one command each; estimated ≈ 0,02 € for ≈ 250 Haiku pairs).** Put the key in the server `.env`, switch on
   `llm.matching.enabled` for the run, then
   `pnpm --filter @pretoscop/worker match:eval:llm --mask` and `pnpm --filter @pretoscop/worker match:eval:llm`.
   Each prints precision at 0,80–0,98, the cost per 1,000 pairs from the ledger and PASS / FAIL /
   INCONCLUSIVE (inconclusive until ≥ 50 real-labelled pairs reach the LLM: label 100 pairs with
   `pnpm --filter @pretoscop/worker match:label`). Leave the flag on only on PASS at 0,90.
